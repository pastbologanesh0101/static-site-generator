Welcome to the very first post on this site, generated entirely from a
Markdown file with **YAML front matter**.

## Why another static site generator?

Because it's a great way to see, end to end, how tools like Jekyll and
Hugo actually work under the hood:

1. Parse front matter + Markdown body
2. Render the body into an HTML layout with Jinja2
3. Write the result to a clean-URL output path
4. Generate index, tag, and RSS feed pages from the collection

That's really all there is to it.
